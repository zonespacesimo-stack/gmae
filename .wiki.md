# Project Summary
The project is a web-based game titled "One Shot Challenge," built using the Phaser 3 game engine and Matter.js physics. Players engage in slingshot-based gameplay, aiming to complete procedurally generated levels while managing a coin economy and unlocking various skins. The game emphasizes a premium feel with smooth animations and effects, and is designed to be SEO-optimized to enhance visibility and includes analytics for tracking player engagement.

# Project Module Description
- **index.html**: The main HTML file, optimized for SEO with structured data.
- **style.css**: Stylesheet for a dark theme, featuring a mobile-first responsive design.
- **main.js**: Game entry point with Phaser 3 configuration and scene registration.
- **game.js**: Core gameplay mechanics including slingshot mechanics and restart functionality.
- **levels.js**: Implements infinite procedural level generation with difficulty scaling.
- **effects.js**: Manages visual effects like particles and camera shake.
- **ui.js**: Full menu system including main menu, mode selection, and settings.
- **data.js**: Handles LocalStorage for player progression and analytics.
- **script.js**: Single entry point for Vite bundling, importing all game modules.
- **vite.config.js**: Configuration for Vite build process.
- **robots.txt & sitemap.xml**: SEO files for enhancing search engine visibility.
